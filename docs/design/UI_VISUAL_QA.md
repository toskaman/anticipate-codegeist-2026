# UI v3 visual QA

**Provenance of every image below: MOCK_TRANSPORT.** The real `CoreWorkspace` and `ForgeClient`
validation ran in Chromium with Playwright-routed CORE 0.2.0 envelopes (`tests/core-harness.html`,
banner "MOCK TRANSPORT TEST ONLY"). Data is fictional (`tests/core-showcase-data.ts`,
`example.invalid` links). None of these images is LIVE_FORGE.

Rendering caveat: images were produced by an authoring-environment bundle (esbuild, React 19,
`@xyflow/react` 12.12.1 built from source with its CSS flattened) because npm was not reachable
there. The repository build uses Vite 8, React 18.3 and the published React Flow package; minor
differences (for example React Flow control styling) are possible. Regenerate with the real
toolchain before quoting pixels: `npx playwright test tests/core-visual.spec.ts`.

## Defects found and corrected during the loop

| Found | Fix |
| --- | --- |
| Graph nodes unreadable at 1440 (4 lanes in a 660 px canvas, ~0.45 zoom) | Compact nodes (212 px), lanes wrap at 6 rows, inspector moves below the map under 1600 px, canvas height follows measured aspect ratio. |
| 34-node fan-out shrank to a single tall column | Lane wrapping into sub-columns; unit test asserts no overlap. |
| Hero journey cards cramped beside the headline | Hero stacked; on ≤ 720 px journey becomes a compact 2-column list. |
| Scenario metric labels truncated ("Transiti…") | Tighter cell padding and label size; no ellipsis. |
| "1 uncertainty remain", "1 open question(s)" | Singular/plural copy. |
| Primary buttons rendered with inherited text colour in light theme | Base resets moved to `:where(.ax-app)` (zero specificity). |
| Settings explanation broke into one line per phrase | Wrapped in a paragraph. |
| Horizontal overflow at 320 px (nav grid item, pager, 500-char labels at 200 % zoom) | `min-width: 0` on sidebar/nav, wrapping pager and large buttons, `overflow-wrap: anywhere` on leads. |
| Post-execution warning stayed alarming after records arrived | Neutral "requested once" notice when records exist; warning kept while uncertain. |
| Disabled Approve checkboxes cluttered executed plans | Hidden once execution was requested (guards unchanged). |
| "Generate prevention plan" looked like the recommended path on a blocked option | Secondary style when the verdict is Blocked. |
| Sidebar background stopped at 100 vh in full-page captures | Column background drawn by the app grid. |
